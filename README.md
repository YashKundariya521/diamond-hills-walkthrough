# Diamond Hills Walkthrough

First-person walkthrough of the Diamond Hills flat in Rajkot, built to scale from the architect's furniture layout (9 ft ceilings, 5.5 ft eye level). Every room is furnished, with light baked in Blender.

Open `index.html` in a browser, or serve this folder locally. The file is about 73 MB.

- **Move:** WASD
- **Look:** click and drag
- **Faster:** Shift
- **Furniture sizes:** L
- **Notes:** N
- **Jump to a room:** menu at top left

`index.html` is stored with Git LFS, so install Git LFS before cloning.

`src/` holds the Blender and viewer build scripts. They expect the model packs, materials and plan to be on the local machine and are not self-contained.

Private repository: `index.html` bundles third-party model packs, so check their licences before sharing.
