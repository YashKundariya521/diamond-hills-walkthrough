# Diamond Hills Walkthrough

First-person walkthrough of the Diamond Hills flat in Rajkot, built to scale from the architect's furniture layout (9 ft ceilings, 5.5 ft eye level).

Open `index.html` in a browser, or serve this folder locally. The file is about 134 MB, so it takes a moment to load.

- **Move:** WASD
- **Look:** click and drag
- **Faster:** Shift
- **Furniture sizes:** L
- **Notes:** N

Drawing Room, Living Room and Dining are furnished. The other rooms are still bare shells.

`index.html` is stored with Git LFS, so install Git LFS before cloning.

`src/` holds the Blender and viewer build scripts. They expect the model packs, materials and plan to be on the local machine and are not self-contained.

Private repository: `index.html` bundles third-party model packs, so check their licences before sharing.
